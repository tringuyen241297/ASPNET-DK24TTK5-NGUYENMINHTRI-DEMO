**Giới thiệu**
Dự án xây dựng website bán sản phẩm công nghệ của Apple trực tuyến nhằm hỗ trợ khách hàng tìm kiếm, xem thông tin và đặt mua các sản phẩm Apple một cách nhanh chóng, thuận tiện. Hệ thống đồng thời hỗ trợ quản trị viên quản lý sản phẩm, danh mục, người dùng và đơn hàng hiệu quả.
Website hướng đến giao diện thân thiện, dễ sử dụng và đáp ứng nhu cầu mua sắm trực tuyến của khách hàng.

**Mục tiêu**
Xây dựng hệ thống bán sản phẩm công nghệ của Apple trực tuyến.
Áp dụng kiến thức về ASP.NET và cơ sở dữ liệu vào xây dựng website.
Tối ưu quy trình tìm kiếm, lựa chọn và đặt hàng sản phẩm.
Hỗ trợ quản trị viên quản lý sản phẩm, danh mục, người dùng và đơn hàng.

**Công nghệ sử dụng**
Backend: ASP.NET MVC
Fronted: HTML, CSS, JavaScript, jQuery,
Database : SQL Server
Tool: Visual Studio, GitHub

**Chức năng hệ thống**
**Khách hàng**
Xem danh sách sản phẩm công nghệ của Apple.
Tìm kiếm và lọc sản phẩm.
Xem thông tin chi tiết sản phẩm.
Thêm sản phẩm vào giỏ hàng.
Cập nhật và xóa sản phẩm trong giỏ hàng.
Đặt hàng trực tuyến.
Theo dõi tình trạng đơn hàng.

**Quản trị viên**
Quản lý sản phẩm
Quản lý danh mục
Quản lý đơn hàng
Quản lý người dùng
Thống kê doanh thu

**Hướng dẫn cài đặt và chạy chương trình**

**Clone project:**
git clone https://github.com/tringuyen241297/ASPNET-DK24TTK5-NGUYENMINHTRI-DEMO.git

**Mở project**
Mở project bằng Visual Studio.
Mở file solution (.sln) của dự án.

**Cấu hình Database**
Sử dụng SQL Server.
Import file .sql trong thư mục project vào SQL Server.
Kiểm tra và cập nhật connection string trong project.
Thay đổi tên Server phù hợp với máy tính đang sử dụng để kết nối cơ sở dữ liệu.

**Chạy hệ thống**
Mở project bằng Visual Studio.
Nhấn Run (F5) để khởi động website.
Truy cập website trên trình duyệt để sử dụng hệ thống.
